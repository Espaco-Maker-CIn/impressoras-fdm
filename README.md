## Como contribuir

1. Encontre a pasta do item (ou copie a pasta `_modelo`).
2. Use nomes em minúsculas, sem espaço e sem acento.
3. Atualize o `README.md` do item se algo mudar.
4. Nunca suba senhas, chaves ou dados de Wi-Fi.
